## 二、关键设计决策

### 1. 分支策略
- 新建分支 `v4/week5-sysmlpy-multi-case`
- master 保持 V3 稳定版
- V4 完成后合并

### 2. sysmlpy 集成：打分制非硬阻断
- fatal: 打回重生成
- error: 记录不阻断
- warning: 放行
- sysmlpy 不可用时 fallback 旧正则

### 3. 物理验证：策略模式
- 配置声明 `validate_type`（如 "rc_cutoff"）
- Python 代码每种 type 对应一个验证函数
- 不做通用公式引擎

### 4. 节点3 HITL 位置
- node3_subgraph 成功后 → node3_hitl → Q_physics_validate
- 打回到 repair_mo（复用现有子图自修复循环）

### 5. CSV 列过滤
- 每加新用例必须验证 CSV 信号列正确
- 更新 _is_param_or_meta() 后缀列表

## 三、已识别陷阱（21 项，详见 V4 陷阱分析）
