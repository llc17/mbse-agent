## Modelica 标准库参考（摘自 MSL 4.0.0）

电气域 — 使用 Modelica.Electrical.Analog：
```modelica
model RCLowPassFilter
  // 官方组件：Resistor, Capacitor, Ground, StepVoltage
  Modelica.Electrical.Analog.Basic.Resistor resistor(R={R_val});
  Modelica.Electrical.Analog.Basic.Capacitor capacitor(C={C_val});
  Modelica.Electrical.Analog.Basic.Ground ground;
  Modelica.Electrical.Analog.Sources.StepVoltage src(V=5.0, startTime=0.0);
equation
  connect(src.p, resistor.p);
  connect(resistor.n, capacitor.p);
  connect(capacitor.n, ground.p);
  connect(src.n, ground.p);
end RCLowPassFilter;
```

热域 — 使用 Modelica.Thermal.HeatTransfer：
```modelica
model TwoMasses
  // 官方组件：HeatCapacitor, ThermalConductor, FixedTemperature
  Modelica.Thermal.HeatTransfer.Components.HeatCapacitor mass1(C=15, T(start=373.15, fixed=true));
  Modelica.Thermal.HeatTransfer.Components.HeatCapacitor mass2(C=15, T(start=273.15, fixed=true));
  Modelica.Thermal.HeatTransfer.Components.ThermalConductor conduction(G=10);
  Modelica.Thermal.HeatTransfer.Sensors.TemperatureSensor sensor1;
equation
  connect(mass1.port, conduction.port_a);
  connect(conduction.port_b, mass2.port);
  connect(mass1.port, sensor1.port);
end TwoMasses;
```

RLC 串联谐振（电气域）— 使用 Modelica.Electrical.Analog：
```modelica
model RLCSeries
  // 组件：Resistor, Inductor, Capacitor, Ground, StepVoltage
  Modelica.Electrical.Analog.Basic.Resistor resistor(R=100);
  Modelica.Electrical.Analog.Basic.Inductor inductor(L=0.01);
  Modelica.Electrical.Analog.Basic.Capacitor capacitor(C=2.53e-8);
  Modelica.Electrical.Analog.Basic.Ground ground;
  Modelica.Electrical.Analog.Sources.StepVoltage src(V=5.0, startTime=0.0);
  Modelica.Electrical.Analog.Sensors.VoltageSensor sensor;
equation
  connect(src.p, resistor.p);
  connect(resistor.n, inductor.p);
  connect(inductor.n, capacitor.p);
  connect(capacitor.n, ground.p);
  connect(src.n, ground.p);
  connect(capacitor.p, sensor.p);
  connect(ground.p, sensor.n);
end RLCSeries;
```

运放反相放大器（电气域）— 使用 Modelica.Electrical.Analog：
```modelica
model OpAmpInverting
  // 理想运放反相放大器，G = -Rf/Rin
  Modelica.Electrical.Analog.Basic.Resistor Rin(R=1000);
  Modelica.Electrical.Analog.Basic.Resistor Rf(R=10000);
  Modelica.Electrical.Analog.Basic.Ground ground;
  Modelica.Electrical.Analog.Sources.StepVoltage src(V=0.5, startTime=0.0);
  Modelica.Electrical.Analog.Ideal.IdealOpAmp opAmp;
  Modelica.Electrical.Analog.Sources.SignalVoltage Vcc(V=15.0);
  Modelica.Electrical.Analog.Sources.SignalVoltage Vee(V=-15.0);
  Modelica.Electrical.Analog.Sensors.VoltageSensor sensor;
equation
  // 输入
  connect(src.p, Rin.p);
  connect(Rin.n, opAmp.in_n);
  connect(src.n, ground.p);
  // 反馈
  connect(Rin.n, Rf.p);
  connect(Rf.n, opAmp.out);
  // 运放
  connect(opAmp.in_p, ground.p);
  connect(opAmp.out, sensor.p);
  connect(ground.p, sensor.n);
  // 电源
  connect(Vcc.p, opAmp.Vpp);
  connect(Vcc.n, ground.p);
  connect(Vee.n, opAmp.Vnn);
  connect(Vee.p, ground.p);
end OpAmpInverting;
```

## 规则
1. 使用标准 Modelica 库（Modelica.Electrical.Analog / Modelica.Thermal.HeatTransfer）
2. 必须包含激励源（电压源/热源）和测量点（传感器）
3. 仿真时长合理设置（电气: stopTime=0.01，热: stopTime=1000）
4. 模型类名以字母开头
5. 每个组件和方程加注释，注释中标注参数来源（例：// R=1000 来自需求参数 resistance）
6. 参数用 SI 单位（Ω, F, H, V, A, K, W, J）
7. 【重要】禁止使用 `import Modelica.SIunits`（MSL 4.0 已废弃），参数直接用数值（如 R=1000），不要声明 parameter 类型
